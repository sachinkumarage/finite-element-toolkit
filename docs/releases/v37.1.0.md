# v37.1.0 — Consolidate onto the Full Streamlit GUI

This release is a consolidation, not a new engineering capability: it does
not add, change, or remove any `femtoolkit` library behavior. Versions 36 and
37 each shipped their new workflow in a separate, lightweight quickstart
Streamlit application introduced alongside Version 36, leaving the toolkit
with two Streamlit applications side by side. Version 37.1 merges both
workflows into the existing full engineering GUI and removes the separate
quickstart application, so there is exactly one Streamlit application again.

## Changed

- **Two new pages in the full GUI** (`femtoolkit.gui`) —
  **Adaptive Optimization** (`workflow_pages/adaptive_page.py`) and
  **Multi-Fidelity** (`workflow_pages/multifidelity_page.py`), built the same
  way every other page in `femtoolkit.gui` already is: `AppState`,
  `require_project`, `render_execution_mode_controls` (defaulting to Serial),
  and `femtoolkit.application.exceptions_display.describe_error`. Neither
  page implements any sampling, surrogate, optimization, or fusion logic of
  its own — both call only `femtoolkit.adaptive`/`femtoolkit.multifidelity`
  APIs. Unlike the removed quickstart app's hardcoded demonstration project,
  both pages operate on the user's own current project (`state.project`): a
  design variable is defined directly against whatever project the
  Project/Material/Mesh/Loads pages have already built, and the
  Multi-Fidelity page's low-fidelity beam formula reads its length, height,
  material, and load straight from that same project.
- **`streamlit_app.py` replaced with a thin launcher.** It now only calls
  `femtoolkit.gui.app.main()` — kept so Streamlit Community Cloud's default
  main-file convention (and `streamlit run streamlit_app.py` from muscle
  memory) keeps working. `streamlit run streamlit_app.py` and `streamlit run
  src/femtoolkit/gui/app.py` launch the identical application.

## Removed

- **The separate quickstart application** — `app/streamlit/` (five pages:
  Home, FEA Analysis, Optimization, Surrogate-Assisted Optimization,
  Multi-Fidelity, Results) and the `app/` package it lived in, deleted
  outright. No test existed solely for the quickstart app, so no test was
  removed; every test for `femtoolkit.adaptive`, `femtoolkit.multifidelity`,
  and the rest of the core library is untouched.

## Documentation

- **README.md** — the opening summary now reads "This is the Version 37.1
  release" and gained short Version 35/36/37/37.1 summaries in the same style
  as every prior version; a new "## Version 37.1" section explains the
  consolidation; the "## Running the Streamlit Application" section now
  describes the single full GUI (both launch commands, the complete page
  list, Serial-by-default execution, every expensive run gated behind a
  button) instead of the removed quickstart app; the Version 36/37 sections
  each keep one short note that their Streamlit page was later merged into
  the full GUI; the project-structure tree no longer lists `app/streamlit/`.
- **`docs/gui.md`** — new "Version 36 adaptive optimization integration" and
  "Version 37 multi-fidelity integration" sections describing the two new
  pages; the "Running the GUI" section now lists `streamlit_app.py` as an
  equivalent launcher.
- **`docs/adaptive.md`** and **`docs/multifidelity.md`** — their Streamlit
  sections now point at the full-GUI pages instead of the removed quickstart
  app.

## Testing

- The complete regression suite still passes: **3178 tests total**, all
  passing, zero regressions — this release touches no library code, so no
  test count changed from Version 37.
- `ruff check .` is clean across the full codebase.
- The full GUI was verified with `streamlit.testing.v1.AppTest` exercising
  every page, including both new pages' primary buttons (Add Variable/Run
  Adaptive Study; Generate Samples/Train Discrepancy Model/Predict/Run
  High-Fidelity Verification), with zero exceptions.
- A real `streamlit run streamlit_app.py` server was started locally and
  confirmed to respond (HTTP 200), identically to `streamlit run
  src/femtoolkit/gui/app.py`.
- The 3D Visualization page was confirmed to already degrade cleanly
  (a clear install message, no crash) when PyVista is not installed —
  unchanged behavior from Version 24, re-verified here since
  `requirements.txt` installs only the `gui` extra, not `viz3d`.

## Limitations

Version 37.1 is deliberately scoped to consolidation: no new sampling
strategy, surrogate type, or fidelity model was added, and no page was
redesigned beyond what moving it into `femtoolkit.gui`'s conventions
required. Do not expect any change in engineering capability from this
release — see [`v37.0.0`](v37.0.0.md) and [`v36.0.0`](v36.0.0.md) for the
actual capability additions this release only relocates.
